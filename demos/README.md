# 🎮 Demos

Explore these examples to see Synapse [Core Concepts](../docs/concepts.md) in action and find
inspiration for your own projects.

---

## 🌱 Basic
*Foundational building blocks and essential workflows.*

### 🛠️ [Playground Test](./test/README.md)
An empty scene containing a single state machine—perfect for a safe playground to test your logic
ideas.

### 🧩 [Behaviors in Scenes](./behaviors_in_scenes/README.md)
Learn the core workflow of linking modular behaviors to your state machine nodes.

### 🔗 [Node Paths & References](./node_paths/README.md)
Highlights different ways to reference scene nodes from your state machine behaviors.

### 📂 [Nested State Machines](./nested_state_machines/README.md)
Demonstrates how to model state machines in a hierarchy and share data between parent and child.
